## 出典リンクと周辺店舗データ
- 初期登録186件の「公式栄養ページ」リンクは、各チェーンが現在公開するページへの案内です。登録時の個別商品ページや当時の資料を復元したものではありません。掲載内容が更新されるため、登録値との一致や現在の提供状況は各リンク先で確認してください。各行の確認日は変更していません。
- 周辺店舗検索の結果に「© OpenStreetMap contributors（ODbL）」を表示し、OpenStreetMapの著作権・ライセンス案内ページへリンクします。

## お店の追加リクエスト
- アプリの「お店を提案」から、店名（必須）、展開地域・公式サイト・補足（任意）を入力できます。
- 送信するとGitHubのIssue作成画面に内容を転記します。投稿者はGitHubアカウントでログインし、「Submit new issue」を押して投稿を完了します。未ログイン・未確定の内容は管理者には届きません。
- 公開Issueに投稿されるため、個人情報の入力を避けるようアプリ上で案内しています。
- 管理者は https://github.com/katsucodman/gaishoku-pfc/issues で件名が「[店舗追加希望]」の投稿を確認できます。対応後にコメント・クローズしてください。
- GitHub Pagesのみでは匿名投稿を受信・保存できないため、アカウント不要のフォームにする場合は別のフォーム／受信サービスの設定が必要です。

GPSは HTTPS または localhost で実行してください。
公開Overpassはテスト用途です。本番は商用/許諾済み店舗・地図APIへの差し替えを推奨します。

## 筋トレ記録
- 日付、種目、セットごとの重量と回数、メモを保存・編集・削除
- 履歴の種目フィルタと合計セット数・重量×回数×セット数
- SafariのlocalStorageに端末内保存。JSONバックアップの書き出し・読み込み（ID重複を除いて追加）
- 別端末との自動同期はありません。プライベートブラウズやサイトデータ削除で記録が消える場合があります。
- v7の記録とv7バックアップを読み込み可能。同じ重量・回数のセットへ展開します。

## 配色
- ネイビー（文字・アイコン）、ティール（操作）、コーラル（筋トレ記録）で統一。

## ジム名
- 筋トレ記録に任意のジム名を自由入力できます。保存後、過去に使ったジム名がプルダウンに表示されます。
- v7〜v7.2の記録と旧バックアップはジム名空欄として引き継ぎます。

## 記録履歴と種目別グラフ
- 記録一覧は日付を見出しにして、その日の種目とセットごとの重量・repを表示します。
- 種目名をタップすると同じ種目の全履歴と、日付ごとの最高重量（kg）の推移グラフを表示します。同じ日の複数記録は最高値を使用。

## 筋トレ記録
- 日付、種目、重量、回数、セット数、メモを保存・編集・削除
- 履歴の種目フィルタと合計セット数・重量×回数×セット数

- 別端末との自動同期はありません。プライベートブラウズやサイトデータ削除で記録が消える場合があります。
